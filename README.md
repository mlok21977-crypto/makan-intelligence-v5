# MAKAN Intelligence V5 — نموذج تجريبي

مشروع محلي يعمل بخادم FastAPI وقاعدة SQLite ومحرك OpenAI API لاستخراج بيانات الضيوف من رسائل عربية وملفات DOCX/XLSX.

## تشغيل النظام

1. ثبّتي Python 3.10 أو أحدث.
2. افتحي Terminal داخل مجلد المشروع وشغّلي:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
# source .venv/bin/activate
pip install -r requirements.txt
```

3. انسخي `.env.example` إلى `.env` وأدخلي مفتاح API الخاص بك في `OPENAI_API_KEY` (لا تشاركي المفتاح ولا تضعيه في المتصفح).
4. شغّلي:

```bash
uvicorn server:app --host 127.0.0.1 --port 8000
```

5. افتحي `http://127.0.0.1:8000` في المتصفح.

## ما الذي يعمل؟

- إدخال نص عربي حر وتحليله عبر OpenAI Responses API مع JSON Schema صارم.
- رفع DOCX وXLSX وTXT وCSV؛ حد 5 MB و50,000 حرف لكل طلب.
- مراجعة وتعديل نتائج التحليل قبل اعتمادها.
- حفظ السجلات في SQLite محلياً، وعرضها والبحث فيها.
- تجنب تكرار المقابلة نفسها بحسب اسم الضيف والتاريخ والبرنامج والموضوع.
- يحتوي على سجلين وهميين فقط؛ لا يستورد ملف المؤسسة الحقيقي.

## القيود والأمان

- هذا نموذج أولي **لبيانات تجريبية فقط**؛ لا توجد مصادقة أو إدارة صلاحيات أو بنية نشر آمنة.
- لا تستخدمي معلومات داخلية أو بيانات اتصال حقيقية دون موافقة المؤسسة وسياسة حماية بيانات معتمدة.
- طلبات التحليل ترسل النص إلى OpenAI API؛ ضبطنا `store=False`، لكن سياسة المعالجة والاحتفاظ الفعلية تعتمد على شروط حساب API وإعداداته.
- لا يدعم PDF أو DOC أو XLS القديمة أو الملفات المصورة، ولا يعالج جميع صيغ الجداول المعقدة بدقة تامة.
- بعض المستندات الطويلة أو المشوشة قد تحتاج إلى تقسيم أو تصحيح يدوي. لا تحفظ النتائج قبل مراجعتها.
- استخدام API مدفوع بشكل منفصل عن اشتراك ChatGPT.
- يجب إضافة المصادقة والتشفير وإدارة الصلاحيات وتدقيق الأمان قبل أي نشر مؤسسي.
